# References — Provenance Guide

Store local copies where licensing permits: `docs/references/<manufacturer>_<part>_<rev>.pdf`

Every datasheet-derived claim must cite:

```
Manufacturer | Part number | Document title | Revision/Date | Page/Section | URL or local path
```

Example:

```
Analog Devices | AD5686R | Datasheet Rev C | p.12, Table 2 — INL | https://www.analog.com/... | docs/references/ADI_AD5686R_RevC.pdf
```
