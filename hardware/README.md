# Hardware

KiCad sources are authoritative. Generated Gerbers are artifacts in `manufacturing/`.

- `kicad/` — schematics and PCB
- `symbols/` / `footprints/` — project-local libraries
- `mechanical/` — enclosure, mounting
- `prototypes/` — prototype notes, rework logs

No PCB manufactured until schematic/ERC/simulation/design reviews pass.
